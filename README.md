# 832401313 Calculator Frontend

这是软件工程实践第一次作业的前端项目，页面名称为“832401313 计算器”。它使用原生 HTML、CSS 和 JavaScript，实现表达式输入、后端计算、历史记录查询和记录管理。

## 技术栈

- HTML5
- CSS3
- JavaScript Fetch API

## 运行方法

1. 先启动后端服务，确认 `http://127.0.0.1:5000/api/health` 可以访问。
2. 在本目录执行：

   ```bash
   python -m http.server 5500
   ```

3. 打开 `http://127.0.0.1:5500`。

后端地址在 `app.js` 的 `API_BASE` 中配置。部署时把它改为实际后端地址即可。

## 功能

- 输入基本或复合表达式。
- 支持百分号后缀，例如 `50%` 表示 `0.5`，计算仍由后端完成。
- 通过 HTTP 请求让后端完成计算。
- 展示后端返回的结果和错误信息。
- 从后端数据库读取历史记录。
- 调用后端接口删除指定历史记录或清空全部历史。
- 使用 `Ans` 插入上一次成功结果，支持历史表达式/结果搜索。
- 一键复制结果，支持深色/浅色主题切换。
- 可选择自动、2 位、4 位或 6 位结果显示精度；精度只改变页面显示，不改变后端保存值。
- 历史记录可收藏、按“只看收藏”筛选，点击表达式即可放回输入框复用。
- 支持 Enter 计算、Esc 清空和退格快捷操作。
- 使用福州大学校园图片作为背景，并通过遮罩保证内容可读性。
