# 832401313 Calculator Frontend

这是软件工程实践第一次作业的前端项目。它使用原生 HTML、CSS 和 JavaScript，实现表达式输入、后端计算、历史记录查询和指定记录删除。

## 技术栈

- HTML5
- CSS3
- JavaScript Fetch API

## 运行方法

1. 先启动后端服务，确认 `http://127.0.0.1:5000/api/health` 可以访问。
2. 在本目录执行：

   ```bash
   python -m http.server 5500
   ```

3. 打开 `http://127.0.0.1:5500`。

后端地址在 `app.js` 的 `API_BASE` 中配置。部署时把它改为实际后端地址即可。

## 功能

- 输入基本或复合表达式。
- 通过 HTTP 请求让后端完成计算。
- 展示后端返回的结果和错误信息。
- 从后端数据库读取历史记录。
- 调用后端接口删除指定历史记录。
